# Changelog

## 0.2.0 — Wooden frames and separate boards

- Added resizable wooden frames, independent corkboards, a saved-notes drawer, lockable pins, colored threads, labels, and rich text.

## 0.1.1 — Reliable tray minimize

- Verified Windows tray registration before hiding the board and kept the taskbar button available when registration failed.

## 0.1.0 — First corkboard

- Added a draggable corkboard, local autosave, pop-out notes, a tray icon, and an optional Windows startup setting.
