# Security policy

Security fixes are considered for the latest version on `main`.

Use [GitHub private vulnerability reporting](https://github.com/JFellores/Classic-Corkboard/security/advisories/new) when it is available. If the form is unavailable, open an issue asking the maintainer for a private channel and leave out the vulnerability details. Include the affected version, reproduction steps, and impact once you have a private channel. Use sample notes and images in place of personal data.
